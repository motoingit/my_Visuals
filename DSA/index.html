AVL rotations: the full story

Each case replays one real insertion with numbers: before, insert, update, detect, rotate, after. BF = height(left) − height(right), h = height of the subtree.

Colors: amber = being compared, green = new or fixed, blue = being updated or part of the rotation, red = AVL rule broken (|BF| > 1). Letters z, y, x name the unbalanced node and the two nodes below it on the heavy path. Arrow keys also step.
